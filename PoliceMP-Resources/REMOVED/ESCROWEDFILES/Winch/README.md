# [Advanced Winch](https://fivem.nabla-corporation.com/package/4798764) (36$)  
With this script, you’ll be able to attach an entity to any other entity !  

Video available [here](https://youtu.be/4Q4jh8q8Gco)  
You can test our scripts for free [here](https://servers.fivem.net/servers/detail/p6mo4m)  

## Features
✅ Attach vehicles, pedestrians and objects with a rope gun  
✅ Ability to winch yourself (animation to do)  
✅ Rope attach point selection uses mouse and left click  
✅ Multiple ropes  
✅ Control length of individual ropes  
✅ Cut ropes  
✅ Manage all ropes at the same time  
✅ Highly customizable (weapon used, text, controls, lengths, rope type, notification style...)  
✅ Network synchronized  
✅ Whitelist some users (can be removed)  
✅ Blacklist some entity models or types (peds, other players, vehicles, objects)  
✅ Uses `RegisterKeyMapping` so users can modify their keybinds  
⚠️ Uses FiveM Asset Escrow system  
  
## Controls
- <kbd>E</kbd> Activate the rope point selection press  
- <kbd>Mouse Left</kbd> Select a point for the rope press  
- <kbd>Page Up</kbd> Wind current rope  
- <kbd>Page Down</kbd> Unwind current rope  
- <kbd>B</kbd> Cut current rope  
- <kbd>&larr;</kbd> / <kbd>&rarr;</kbd> Select rope  
- <kbd>Left Shift</kbd> Select all rope
