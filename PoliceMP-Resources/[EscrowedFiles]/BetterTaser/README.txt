BetterTaser by Mirror Park Studios introduces the most realistic taser script on the market, which has been influenced by police officers trained on the devices in real life.
It includes a realistic UI for the X2 taser, a flashlight, red dots, x26 and x2 compatibility, and all the standard taser functions such as reactivation, (drive stun on x26), and arcing.
All the functions are easily keybinded using FiveM's inbuilt keybind system, so your server members can set their own keybinds in the keybind menu.
It also includes logging for safety deactivation and taser firing, to keep track of your standards.

**COMMANDS**
/rt - reloads your taser with any spare cartridges
/resettaser - Fully resets your taser, including battery
/reactivate1 or /reactivate2 - reactivates any active barbs
/ts - toggles taser safety
/arv - arcs your taser
/rb1 or /rb2 - removes barbs set 1 or barbs set 2
/taserLight - toggles taser flashlight

**CONFIGURATION**
Allows you to set the weapon hashes for the x2 or x26 weapons
Allows you to enable logging, and set the webhook link.

**INSTALLATION**
Setup your configuration file to your liking
Download and install screenshot-basic (https://github.com/citizenfx/screenshot-basic)
and discord-screenshot (https://github.com/jaimeadf/discord-screenshot/releases/tag/1.3.7)
Make sure to also put your webhook URL in your discord-screenshot settings.json.
