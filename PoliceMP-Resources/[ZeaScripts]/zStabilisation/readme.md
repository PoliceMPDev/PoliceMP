# zStabilisation by Zea Development

Introducing zStabilisation, This resource allows for a realistic and more in-depth experience when it comes to stabilising vehicles. This resource does not freeze any vehicles but instead requires the effective placement of realistic stabilisation equipment to prevent the vehicle from moving. zStabilisation is fully synced between players, meaning all props spawned can be edited and deleted by anyone. zStabilisation further includes a sandbox-style prop spawner, allowing you to precisely place equipment where you need it.

# Usage:

After zStabilisation is initiated, the client will be able to enter a range of commands that are adjustable in the Settings.json file. By entering this command, the client will enter EDIT MODE, where they will be able to manoeuvre the prop into the correct position before placing it.

When a prop has been set, clients may interact with it by editing it, which makes it possible to move it. Clients can also delete the prop.

# Base Commands:

The following are all commands and their usages,

/Stabfast - Place a Stabfast Stabiliser
/Paratech - Place a Paraetch Vehicle Shoring Strut
/Tarp - Place a Tarp / Salvage Sheets
/StepChock - Place a Step Chock / Block
/Wedge [Size] - Place a Plastic Wedge
/Platform [Size] - Place a Heavy Goods Vehicle(HGV) Platform
/Block [Size] - Place a Plastic Cirbbing Block

# Movement Syncing:

Movement Syncing can be toggled within the Settings.json file. This boolean is found within the editor settings category.

If movement syncing is on, all players will be able to see prop movement without lag; WARNING this may cause optimisation issues within the server while in use. If the movement syncing option is false, props will be placed normally but will not be fully synced between players while they are being moved. This allows for greater optimisation of the resource while in use.
