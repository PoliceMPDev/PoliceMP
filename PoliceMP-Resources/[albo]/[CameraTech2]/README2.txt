CameraTech for FiveM by Albo1125 - FMS addon
First, download and install the CameraTech resource following the instructions in the README
https://github.com/Albo1125/CameraTech/releases

The FMS addon includes a custom vars.lua that checks the FMS to see if the user has permission ID 74 during patrols.
Replace the vars.lua in the original CameraTech folder with this one to enable this custom FMS whitelisting.
