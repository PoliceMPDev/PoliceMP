# PoliceMP Codebase

This repository contains the **leaked PoliceMP codebase and resources** for development, research, and reference purposes.

## Repository Structure

The repository is split into two main folders:

* **`PoliceMP/`** — Contains the main PoliceMP C# codebase, including the `.sln` solution file.
* **`Policemp-Resources/`** — Contains the EUP / Vehicles / mappings / scripts used alongside the codebase. If its escrowed, then touch luck! Else, free to rip :)

## Requirements

This is **not a ready-to-run project**.

To fully understand, build, modify, or make use of this repository, you will need a reasonable level of experience with:

* **C# / .NET development**
* **Visual Studio and `.sln` solutions**
* Building and debugging C# projects
* Understanding project dependencies and configuration
* Basic **PowerShell** knowledge

Knowledge of PowerShell is particularly useful if you intend to use, modify, or create automation scripts around the project.
